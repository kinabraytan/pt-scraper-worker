# Security Policy

## Supported Versions

Please see our current supported versions. Security updates will only be provided for the latest active release.

## Reporting a Vulnerability

We take the security of this project seriously.

If you believe you have found a security vulnerability, please do NOT report it in the public issue tracker. Instead, please report it via private disclosure.

### What to include

When reporting a vulnerability, please provide the following details:
- A description of the vulnerability.
- Steps to reproduce.
- Any potential impact.

We will acknowledge receipt of your report and work to address it promptly.
