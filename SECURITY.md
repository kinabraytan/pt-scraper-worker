# Security Policy

## Supported Versions

The following versions of the PT-Scraper Worker are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of PT-Scraper seriously. If you discover a security vulnerability in this project, please **do not** open a public issue.

Instead, please report it via one of the following methods:

1. **GitHub Security Advisory:** Create a private security advisory on GitHub if this repository has the feature enabled.
2. **Direct Contact:** If a private advisory cannot be created, contact the project maintainers directly via a secure channel.

When reporting a vulnerability, please include as much information as possible, such as:
- A detailed description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant context or potential fixes.

You should expect a response from the maintainers within 48 hours acknowledging receipt of the vulnerability report. We will keep you updated on the progress of addressing the issue and notify you when a fix is available.
