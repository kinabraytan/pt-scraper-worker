## Reporting a Vulnerability

We take the security of our systems seriously. If you believe you have found a security vulnerability in our codebase or releases, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately by emailing the security team or the project maintainers.
We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you're curious about the status of your report, please feel free to reach out to us again.
